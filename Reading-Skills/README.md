# 📘 Reading Skills

An interactive, single-page web app for practicing English reading skills. It runs entirely in the browser: no server, no build step, no dependencies.

Ứng dụng web một trang để luyện kỹ năng đọc tiếng Anh. Chạy hoàn toàn trên trình duyệt, không cần cài đặt.

## Features

- 10 units, each with reading skills, vocabulary and exercises
- Multiple choice, fill-in-the-blank, true/false, matching, ordering and drag-and-drop activities
- Click a word in a reading to save it, then review with flashcards
- Highlighting and annotating tools
- XP, streaks and a Progress page
- Light/dark theme and sound toggle
- Backup / Restore of your progress (💾 button)

## Run locally

Open `index.html` in any modern browser. That's all.

## Deploy with GitHub Pages

1. Push `index.html` to the `main` branch of this repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. After a minute your site is live at `https://tranyen17805-ship-it.github.io/Reading-Skills/`.

## Your data

Progress, saved words, answers and highlights are stored only in your own browser (`localStorage`). Nothing is sent anywhere. Clearing site data or switching browser/device starts you from zero; use **Backup / Restore** to move your progress.
